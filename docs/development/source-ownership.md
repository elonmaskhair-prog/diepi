# 首次公开候选的源码权属记录

记录日期：2026-08-12。

项目所有者在首次公开前审阅中确认：当前公共候选白名单内的 dieΠ 源码为项目自研代码，
不存在“只读上游快照”、复制后修复的第三方代码库，或需要继承的上游 Git 历史。仓库按
Apache-2.0 许可发布源码；依赖包仍分别受其自身许可证约束，见
`THIRD_PARTY_NOTICES.md`。

这项确认只覆盖 `tools/public_git_allowlist.txt` 明确列出的首次候选，不会自动覆盖未来贡献、
新依赖、复制的示例、数据集、模型、生成代码或二进制资产。后续新增内容仍须单独确认来源、
许可和必要的 copyright / NOTICE 保留要求。

行情、策略、回测结果与 synthetic demo 不属于同一种权属判断。内置 `diepi demo` 数据仍由
仓库代码确定性生成并明确标记为虚构数据；用户行情、策略和结果默认不进入公共候选。

2026-08-17，项目所有者另行确认：`examples/market_data_v1/data` 中精确列出的四证券、
2026 年上半年规范化真实行情小切片可以随公开源码和 sdist 分发。该确认只覆盖公共白名单
中的固定样例文件，不覆盖完整本地行情库、上游源文件、其他日期或证券，也不表示代码的
Apache-2.0 许可自动覆盖任何行情数据。样例构建器只投影 v1 必需列，不记录本机绝对路径；
wheel 不携带该切片。

内置 `cn-a-share-2010-2026-v1` 日历是依据沪深交易所公开休市公告重建的日期事实表，
不含上游代码或第三方行情字段。来源入口、覆盖期和稳定内容摘要保留在
`diepi/backtest/data/calendar.py`；未来扩展年份时必须重新核验公告并升级日历身份。
