# 维护者文档

本目录用于可公开的维护者材料，例如架构决策、发布流程、兼容性说明和开发约定。它不是
用户手册，也不进入源码发行包或 wheel。

面向用户且承诺支持的行为应写入 `docs/product/`。影响策略写法、订单执行或结果可比性的
内容，必须同时反映在产品文档中，并由代码和测试支持。维护者记录可以解释决策原因，但
不能成为公开契约的唯一来源。

## 当前公开状态

当前 diePi 公共源码历史和 `0.1.0` release 于 2026-08-18 建立并发布。当前正式工作树以
公开 `main` 为基线，在 `release/0.1.1` 分支审阅补丁候选；具有公共 Git 来源不表示该候选
已经合并、发布或上传，也不得绕过 PR、CI 与 tag 门禁直接进入发布渠道。

`docs/audit/` 与 `docs/stage1_notes.md` 仍属于本地审阅材料，已被精确公共树白名单排除，
也不进入 sdist 或 wheel。后续若要公开其中任何材料，必须逐份批准和脱敏，并显式加入
`tools/public_git_allowlist.txt`；`.gitignore` 本身不是隐私边界。

不要在本目录放置凭据、个人路径、专有策略、受许可约束的行情、原始结果产物或未脱敏的
漏洞报告。适合长期保留的记录应使用可移植示例，并在需要时链接稳定符号、测试或发布
门禁。

`0.1.1` 的候选边界、源目录和授权检查见
[`first-public-release.md`](first-public-release.md)；本轮项目所有者对候选源码来源的确认见
[`source-ownership.md`](source-ownership.md)。
