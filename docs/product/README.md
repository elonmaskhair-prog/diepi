# dieΠ 产品文档

这组文档从同一份当前实现出发，服务不同阅读目的。作者序已合并到项目首页；
核心功能、用户手册和参考与边界是三层产品契约，本地行情数据格式是面向数据
生产者的专项规范；它们不互相复制功能列表。

dieΠ 面向普通本地用户开放，但不会替用户取得、下载或授权行情。首批最顺畅的用户是
已经拥有本地 Parquet 行情、希望把数据与策略留在自己电脑上的研究者。没有真实行情也
可以先运行内置生成器创建的 synthetic demo，验证安装和完整流程；该数据不是市场样本，
其收益没有研究含义。

- [项目首页](../../README.md)：判断 dieΠ 是否适合你，并完成第一次运行。
- [作者序（可选）](../../README.md#写在项目前为什么做-dieπ)：了解项目来由和作者的研究反思；不是使用前置条件。
- [核心功能](02-core-features.md)：理解因果边界、双价格轨、市场规则、审计证据和可比性门禁。
- [用户手册](03-user-guide.md)：5/15/30 分钟上手、准备数据、三种输入、combo bundle v1、运行和读取结果。
- [参考与边界](04-reference-and-boundaries.md)：查询精确契约、默认值、能力状态、限制和排错入口。
- [本地行情数据格式 v1](05-local-market-data-format-v1.md)：查询 Parquet 目录、每个文件的列名、dtype、单位、分片和切片契约。

首次使用建议按“[项目首页](../../README.md) → [用户手册](03-user-guide.md)”走通一次；
评估模型是否适合研究问题时，先读[核心功能](02-core-features.md)和
[参考与边界](04-reference-and-boundaries.md)；准备自己的行情时，以
[本地行情数据格式 v1](05-local-market-data-format-v1.md)为唯一规范。

## 文档约定

- **正式支持**：当前面向普通用户的日线现金研究闭环，已有公开入口、明确契约和回归测试。
- **高级**：已有实现，但需要使用者理解更细的数据、执行或组合语义。
- **实验性**：当前可以试用，但模型或接口仍可能变化，不属于首批稳定承诺。
- **部分支持**：仅在文档列出的数据、品种或调用路径内成立。
- **兼容路径**：为旧 Provider 或旧产物保留的退化入口，不具备完整严格证据。
- **不支持**：当前没有可依赖的公开实现。

每个涉及实现的章节都提供“源码定位”，同时写出：

- 仓库相对路径；
- 编写时的当前行号；
- 更稳定的类名、函数名或常量名。

代码演进会使行号漂移；遇到这种情况，应以符号名搜索结果为准。文档若与版本化 `result_contract` 或测试契约冲突，以对应版本的代码和结果契约为准，并请提交文档问题。

## 文档边界

这组文档描述 dieΠ `0.1.1` Alpha 当前工作树，不把架构设想写成已实现能力。
`dieΠ` 是项目品牌，ASCII 发行名和 CLI 命令为 `diepi`；公开 Python API 位于
`diepi.backtest` / `diepi.futures` / `diepi.artifacts`，编排 adapter 使用版本化
`diepi.integration` capability 契约。GUI 是 Python 包/wheel 的正式可选功能；当前不提供或
承诺 Windows/macOS/Linux 的独立安装器。Roadmap、多策略实验
编排、通用插件系统、实盘交易和尚未接入的历史数据快照，应放在独立规划文档中。
